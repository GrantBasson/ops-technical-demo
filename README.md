# ops-technical-demo
Private draft for an operations technical demonstration.

The intention of this repository is to demonstrate technical understanding and competence in operations related tasks within a payments environment. It includes both working code and screenshots demonstrating live interactions with a variety of relevant software, data, and simulated real-life queries.
